# Demo ContiCredito

Demo interactiva de la plataforma web de préstamos propuesta para ContiCredito. Todos los datos son ficticios.

Es un único archivo estático (`index.html`), sin dependencias ni proceso de compilación.

- `?tour` inicia el recorrido guiado al abrir la página.
- `?admin` abre directamente el panel administrativo.

Preparado por Giancarlos Ormeño.
